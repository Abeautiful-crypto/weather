# 动态天气背景 + 视觉细节提升（设计）

日期：2026-09-22 ｜ 范围：`weather-go/web/index.html`（单文件）

## 目标

把"按天气切换三色渐变"的静态背景升级为**随城市天气变化的动态氛围**，并提升卡片层次、排版节奏与数据可读性。

## 非目标

不引入图片/字体/图标库/框架；不重排布局、不改模块顺序与 DOM id；不做雷达、地图、粒子物理。

## 约束

零外部请求（唯一网络仍是本机 `/api/*`）；单文件 + `go:embed`；支持 `prefers-reduced-motion`；375px 不溢出。

## 已确认决策

| 议题 | 结论 | 依据 |
|---|---|---|
| 背景形态 | 纯代码（CSS + 单层 canvas） | 内嵌图片会让单文件从 54KB 涨到数百 KB～MB |
| 改造范围 | 背景 + 视觉细节，布局不动 | 只动背景会有割裂感；整体重排的风险收益不匹配 |
| 风格 | 自然沉浸式（类 iOS 天气） | 动效慢而不抢眼，保证数据可读 |

## 技术方案

| 层 | 实现 | 动效 |
|---|---|---|
| `.bg-sky` | 现有 3 层渐变，保留结构 | 60s 极缓位移+缩放 |
| `.bg-cloud` | 多层 `radial-gradient`+`blur` | 20~40s 横移，透明度随云量 |
| `.bg-glow` | 径向暖光斑 | 25s 呼吸+漂移，仅白天晴 |
| `canvas#fx` | `fixed; z-index:-1; pointer-events:none; aria-hidden` | 雨丝/雪花/雾絮 |
| `.bg-flash` | 白色覆盖层 | 仅雷暴：随机 3~6s 二次闪 |

粒子用 canvas 而非 DOM：几十到几百个粒子用 div 会持续触发布局与合成，canvas 单次绘制可控且密度/倾角可精确调。

### 性能与降级（必做）

- 粒子数按视口面积与 `devicePixelRatio` 计算并设硬顶（雨≤220、雪≤160、雷暴≤240）
- `document.hidden` 暂停 rAF，恢复时重置时间基准（避免瞬移）；`resize` 防抖重建
- 只用 `transform`/`opacity`，不逐帧改 `top/left/filter`
- `prefers-reduced-motion: reduce` → 不启动 canvas、关闭云/光斑/闪电，仅保留静态渐变（仍随天气换色）
- 卡片加暗遮罩，保证正文对比度 ≥ 4.5:1

## 视觉方案

### 配色：7 组基准色 + 统一昼夜调制

不再硬写 14 套色板：每个 kind 一组基准色，夜间统一"降明度+降饱和+加冷"。当前问题是除晴天外色相接近、明度都低，视觉上"灰成一团"。

### 各天气动效

| 天气 | 背景 | 粒子 |
|---|---|---|
| 晴·昼 | 天蓝大色域 + 暖光斑呼吸 | 无 |
| 晴·夜 | 深蓝→靛 + 极淡星点（微视差） | 无 |
| 多云/阴 | 软云漂移 30s（2~3 团不同速） | 无 |
| 雨 | 下沉冷蓝 + 云更快 + 底部湿反光 | 雨丝 60/140/220（小/中/大），**倾角随风速** |
| 雪 | 冷白蓝 + 慢云 | 雪花 80~160，横向摆动 + 大小差 |
| 雾 | 低饱和灰白 | 缓慢横移的柔光雾絮 |
| 雷暴 | 紫黑 + 厚云 | 雨丝 240 + 风摆；闪电 |

### 细节提升（8 项）

1. Hero：温度 72→92px、字重 300、`tabular-nums`；图标加大 + 同色辉光；副标题改三个胶囊
2. 卡片层次分 3 档；阴影双层（近硬+远柔）；描边改上亮下暗 1px 渐变
3. 指标网格：数值等宽数字，单位与数字分色
4. 逐小时折线改平滑曲线（Catmull-Rom），节点只留首尾与极值
5. 7 天温度条按冷暖做蓝→橙渐变填充
6. 排版：4 级字号（12.5/14/20/92）+ 8px 间距栅格
7. emoji 统一饱和度与基线对齐
8. 卡片暗遮罩保证对比度下限

## 对既有验收项的影响

网络行为零变化（"无第三方域名"仍成立）；模块 DOM/id 不变（Go 侧测试不受影响）；375px 响应式需重测；`-web-dir` 与 embed 两种形态都要实测。

## 验收标准

- [ ] 控制台 0 errors / 0 warnings
- [ ] Performance API 只出现本机域名
- [ ] 7 种天气的动效与粒子正确切换（注入各 weather_code 验证）
- [ ] 雨天倾角随风速变化、密度随降水强度区分
- [ ] `prefers-reduced-motion` 下无 canvas、无动画、仍随天气换色
- [ ] 切标签页后 rAF 停止
- [ ] 375px `scrollWidth == innerWidth`
- [ ] 最亮背景态下卡片正文对比度 ≥ 4.5:1
- [ ] 提醒条/错误卡片/骨架屏/toast 未被破坏
- [ ] 仍是单个 `index.html`，无新增资源文件
- [ ] `go test ./...` 与 `go test -race ./...` 仍全绿

## 风险与遗留

- emoji 跨系统渲染差异大，"图标统一"只能有限一致（零依赖的代价）
- 低端设备仍可能掉帧，必要时再按 `navigator.hardwareConcurrency` 进一步降密度
- 本设计只覆盖视觉层；若日后要"沉浸式首屏"需另开一轮设计
